# Configuración de la búsqueda

Specra incluye búsqueda de texto completo impulsada por [MeiliSearch](https://www.meilisearch.com/). Tú mismo ejecutas MeiliSearch, indexas tu documentación en él y Specra lo consulta por ti. Esta guía recorre todo el flujo.

<Callout type="info">
  **Tú eres dueño del índice.** La indexación envía tu contenido a *tu* servidor de MeiliSearch — no se sube nada a Specra. Una opción de búsqueda alojada (indexar desde el CLI, servida en un subdominio de Specra) está en la hoja de ruta; por ahora, la búsqueda es autoalojada.
</Callout>

## Opciones de búsqueda

| Opción | Configuración | Ideal para |
|--------|-------|----------|
| **Búsqueda local** (predeterminada) | Ninguna | Sitios pequeños; busca en el navegador |
| **MeiliSearch** (recomendada) | Ejecutar un servidor + indexar | Sitios medianos/grandes; resultados instantáneos, tolerantes a errores tipográficos y con reconocimiento de idioma |

El resto de esta guía cubre MeiliSearch. Si solo quieres búsqueda sin configuración, salta a [Búsqueda local](#búsqueda-local-alternativa).

## Cómo encaja todo

```txt
Navegador  ──GET /api/search?q=…──▶  Tu app de Specra (servidor)  ──▶  Tu servidor de MeiliSearch
   ▲                                        │
   └──────────── resultados ◀───────────────┘
```

El navegador solo se comunica con la ruta `/api/search` de tu propia app. Esa ruta se ejecuta en el servidor, lee tus credenciales de MeiliSearch desde `specra.config.json` y reenvía la consulta. Tu host de MeiliSearch y tu clave de API **nunca quedan expuestos al navegador**, y no hay preocupaciones de origen cruzado (CORS).

## Inicio rápido

**Requisitos previos:** tu sitio de documentación de Specra (ya configurado) y un servidor de MeiliSearch (iniciamos uno a continuación).

### 1. Ejecuta un servidor de MeiliSearch

Elige la opción que te resulte más fácil.

**Opción A — binario independiente (sin Docker, sin root):**

```bash
# Descarga el binario en la carpeta actual
curl -L https://install.meilisearch.com | sh

# Ejecútalo con una clave maestra (elige la tuya)
./meilisearch --master-key="aSampleMasterKey" --http-addr=127.0.0.1:7700
```

**Opción B — Docker:**

```bash
docker run -d \
  --name meilisearch \
  -p 7700:7700 \
  -e MEILI_MASTER_KEY="aSampleMasterKey" \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest
```

De cualquier forma, MeiliSearch ahora está escuchando en `http://localhost:7700`. Verifícalo:

```bash
curl http://localhost:7700/health
# {"status":"available"}
```

<Callout type="warning">
  `aSampleMasterKey` es solo para desarrollo local. Usa una clave maestra larga y aleatoria en producción.
</Callout>

### 2. Habilita la búsqueda en specra.config.json

Apunta Specra a tu servidor. La `apiKey` aquí se usa tanto para indexar como para consultar, así que para desarrollo local establécela en el **mismo valor** que la clave maestra de MeiliSearch.

```json
{
  "search": {
    "enabled": true,
    "provider": "meilisearch",
    "placeholder": "Search documentation...",
    "meilisearch": {
      "host": "http://localhost:7700",
      "apiKey": "aSampleMasterKey",
      "indexName": "docs"
    }
  }
}
```

### 3. Indexa tu contenido

Specra incluye un indexador. Desde la raíz de tu proyecto:

```bash
npm run index:search
```

Lee `specra.config.json`, recorre cada versión y configuración regional bajo `docs/`, extrae el texto buscable y envía los documentos a tu servidor de MeiliSearch. Vuelve a ejecutarlo cada vez que cambie tu documentación.

<Callout type="info">
  La indexación es asíncrona del lado de MeiliSearch. Espera un par de segundos y luego verifica con `npm run test:search`.
</Callout>

### 4. Pruébalo

Inicia tu servidor de desarrollo y abre la caja de búsqueda con **⌘K** (macOS) o **Ctrl+K** (Windows/Linux):

```bash
npm run dev
```

Empieza a escribir para ver resultados instantáneos.

## Referencia de configuración

Todos los ajustes viven bajo `search` en `specra.config.json`:

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `enabled` | boolean | Activa o desactiva la búsqueda |
| `provider` | `"meilisearch"` \| `"local"` | Backend de búsqueda |
| `placeholder` | string | Texto de marcador en la caja de búsqueda |
| `meilisearch.host` | string | URL de tu servidor de MeiliSearch |
| `meilisearch.apiKey` | string | Clave usada para indexar y consultar |
| `meilisearch.indexName` | string | Nombre del índice (p. ej. `docs`) |

## Búsqueda con reconocimiento de idioma

Si tu sitio usa i18n, la búsqueda se acota automáticamente al idioma del lector — sin configuración adicional. El indexador almacena un campo `locale` en cada documento, y `/api/search` filtra los resultados al idioma que el lector está viendo actualmente, de modo que quien lee la documentación en francés solo ve coincidencias en francés. El selector de idioma del encabezado y la búsqueda se mantienen sincronizados.

## Producción

### Aloja MeiliSearch

Para producción alojas MeiliSearch en algún lugar que tu app pueda alcanzar:

- **[MeiliSearch Cloud](https://www.meilisearch.com/cloud)** — gestionado, con copias de seguridad y actualizaciones automáticas.
- **Tu propio VPS** (DigitalOcean, AWS, Fly.io, Railway, Render…) — ejecuta el binario o la imagen de Docker, idealmente detrás de HTTPS.

Luego establece `meilisearch.host` en la URL de ese servidor.

### Usa una clave con privilegios mínimos

Como las consultas pasan por tu `/api/search` del lado del servidor, la `apiKey` nunca llega al navegador. Aun así, dale a la app una clave **solo de búsqueda** y reserva la clave maestra para la indexación.

Crea una clave solo de búsqueda a partir de tu clave maestra:

```bash
curl -X POST 'https://your-meilisearch-host/keys' \
  -H 'Authorization: Bearer YOUR_MASTER_KEY' \
  -H 'Content-Type: application/json' \
  --data-binary '{
    "description": "Search key for docs",
    "actions": ["search"],
    "indexes": ["docs"],
    "expiresAt": null
  }'
```

Usa la clave devuelta como `meilisearch.apiKey` en tu `specra.config.json` de producción, e indexa con la clave maestra (ver CI abajo).

### Indexa en el despliegue (CI/CD)

El indexador lee su host y su clave desde `specra.config.json`. Para indexar con tu **clave maestra** en CI sin confirmarla en el repositorio, genera la configuración (o sobrescribe la clave) en tiempo de compilación a partir de un secreto. Un trabajo mínimo de GitHub Actions:

```yaml
name: Index docs
on:
  push:
    branches: [main]
    paths: ['docs/**']

jobs:
  index:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm ci
      # Inyecta la clave maestra en la configuración solo para indexar
      - run: |
          node -e "const f='specra.config.json',c=require('./'+f);
            c.search.meilisearch.host=process.env.MEILI_HOST;
            c.search.meilisearch.apiKey=process.env.MEILI_MASTER_KEY;
            require('fs').writeFileSync(f, JSON.stringify(c,null,2));"
        env:
          MEILI_HOST: ${{ secrets.MEILI_HOST }}
          MEILI_MASTER_KEY: ${{ secrets.MEILI_MASTER_KEY }}
      - run: npm run index:search
```

Publica tu app con la clave **solo de búsqueda** en `specra.config.json`, y deja que CI intercambie la clave maestra únicamente para el paso de indexación.

## Personalizar el índice

El comportamiento de la indexación vive en `scripts/index-search.ts`. Hoy configura MeiliSearch así:

```ts
await index.updateSearchableAttributes(["title", "content", "tags"])
await index.updateFilterableAttributes(["version", "locale", "category", "tags"])
await index.updateSortableAttributes(["title"])
await index.updateDistinctAttribute("id")
await index.updateSettings({
  rankingRules: ["words", "typo", "proximity", "attribute", "sort", "exactness"],
})
```

Edita ese script para cambiar qué es buscable, añadir sinónimos o palabras vacías, o ajustar el ranking — luego vuelve a ejecutar `npm run index:search`.

## Búsqueda local (alternativa)

¿No quieres ejecutar un servidor? Usa la búsqueda local integrada:

```json
{
  "search": {
    "enabled": true,
    "provider": "local",
    "placeholder": "Search documentation..."
  }
}
```

- ✅ Funciona de inmediato, sin servidor, gratis
- ❌ Sin tolerancia a errores tipográficos, ranking más débil, más lento en sitios grandes

## Atajos de teclado

- **⌘K** / **Ctrl+K** — abrir la búsqueda
- **↑ / ↓** — moverse entre resultados
- **Enter** — abrir el resultado seleccionado
- **Esc** — cerrar la búsqueda

## Solución de problemas

**La caja de búsqueda no aparece** — confirma que `search.enabled` sea `true` en `specra.config.json`.

**MeiliSearch inalcanzable** — comprueba el servidor:

```bash
curl http://localhost:7700/health   # expect {"status":"available"}
```

**Sin resultados** — vuelve a indexar y confirma que el índice existe:

```bash
npm run index:search
curl -H "Authorization: Bearer YOUR_KEY" http://localhost:7700/indexes
```

**`/api/search` devuelve "Search is not enabled"** — la ruta lee `specra.config.json`; asegúrate de que `enabled` sea `true` y `provider` sea `"meilisearch"`, luego reinicia el servidor de desarrollo para que la configuración se vuelva a leer.

**Resultados en el idioma equivocado** — vuelve a ejecutar `npm run index:search` para que cada documento obtenga su campo `locale`.
