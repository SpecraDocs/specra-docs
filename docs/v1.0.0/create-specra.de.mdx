# create-specra

`create-specra` ist das offizielle CLI-Tool zum Erstellen neuer Specra-Dokumentationsseiten. Es richtet alles, was Sie benötigen, in Sekunden ein: Projektstruktur, Abhängigkeiten, Konfiguration und Beispielinhalte.

<Callout type="info">
`create-specra` enthält auch Befehle für Bereitstellung, Authentifizierung und Diagnose. Siehe die vollständige [CLI-Referenz](/docs/v1.0.0/cli/overview) für alle verfügbaren Befehle.
</Callout>

## Schnellstart

Der schnellste Weg, eine neue Dokumentationsseite zu erstellen:

<Tabs defaultValue="npm">
  <Tab label="npm">
```bash
npx create-specra@latest my-docs
```
  </Tab>
  <Tab label="yarn">
```bash
yarn create specra my-docs
```
  </Tab>
  <Tab label="pnpm">
```bash
pnpm create specra my-docs
```
  </Tab>
</Tabs>

Dies erstellt ein neues Verzeichnis namens `my-docs` mit allem konfiguriert und einsatzbereit.

## Was erstellt wird

Wenn Sie `create-specra` ausführen, erhalten Sie folgendes:

```txt
my-docs/
├── src/
│   ├── app.css                    # Globale Stile (importiert specra/styles)
│   ├── app.html                   # HTML-Vorlage
│   └── routes/
│       ├── +layout.server.ts      # Specra-Konfiguration laden
│       ├── +layout.svelte         # Root-Layout mit Specra-Komponenten
│       ├── +page.server.ts        # Startseiten-Weiterleitung
│       └── docs/
│           └── [version]/
│               └── [...slug]/
│                   ├── +page.server.ts   # Dokumentdaten laden
│                   └── +page.svelte      # Dokumentseiten-Renderer
├── docs/
│   ├── v1.0.0/                    # Version 1 Docs (MDX-Dateien)
│   └── v2.0.0/                    # Version 2 Docs (MDX-Dateien)
├── public/
│   └── api-specs/                 # API-Spezifikationsdateien (OpenAPI, Postman)
├── specra.config.json             # Specra-Konfiguration
├── package.json                   # Abhängigkeiten und Skripte
├── svelte.config.js               # SvelteKit-Konfiguration
├── vite.config.ts                 # Vite-Konfiguration
├── postcss.config.mjs             # PostCSS (für Tailwind)
├── tsconfig.json                  # TypeScript-Konfig
└── .gitignore
```

## Vorlagen

`create-specra` bietet drei Vorlagen zur Auswahl:

### Minimal (Standard)

Sauberer Ausgangspunkt mit grundlegender Struktur:
- System-Theme (folgt der Betriebssystem-Einstellung)
- Kartenförmige Seitenleiste mit abgerundetem Container
- Inhaltsverzeichnis aktiviert
- Einfache Docs: Über-Seite, Erste-Schritte-Anleitung, Komponentenbeispiele

```bash
npx create-specra my-docs --template minimal
```

### Book Docs

Wissensbasis-Stil inspiriert von Plattformen wie GitBook:
- Dunkles Theme als Standard
- Bündige Seitenleiste (am Bildschirmrand befestigt)
- Kategorisierte Seitenleiste mit Abschnittsüberschriften (Inhalt, Anpassung)
- Seitenweites Banner
- Versionsbadge in der Seitenleiste
- Reichhaltiger Beispielinhalt mit Karten auf der Startseite

```bash
npx create-specra my-docs --template book-docs
```

### JBrains Docs

Referenzdokumentationsstil mit Tab-Navigation:
- Helles Theme als Standard
- Bündige Seitenleiste (am Bildschirmrand befestigt)
- Tab-Gruppen zur Organisation von Inhalten (Sprache, Multiplattform)
- Zusammenklappbare Baumstruktur-Seitenleiste
- Kein Inhaltsverzeichnis (rechtes Panel)
- Versionsbadge in der Seitenleiste

```bash
npx create-specra my-docs --template jbrains-docs
```

## Interaktives Setup

Wenn Sie `create-specra` ohne Optionen ausführen, werden Sie aufgefordert:

**Projektname** (falls nicht als Argument angegeben)
```bash
npx create-specra@latest
# Aufforderung: What is your project named?
```

**Vorlage** (falls nicht über `--template` angegeben)
```bash
# Wird fragen: Which template do you want to use?
# Optionen: Minimal, Book Docs, JBrains Docs
```

**Bevorzugter Paketmanager** (falls mehrere erkannt werden)
```bash
# Wird fragen: Which package manager do you want to use?
# Optionen: npm, yarn, pnpm
```

Das CLI erkennt, was auf Ihrem System verfügbar ist, und schlägt die beste Option vor.

## Befehlsoptionen

### Grundlegende Verwendung

```bash
npx create-specra@latest [project-name] [options]
```

### Beispiele

**Mit einem bestimmten Namen erstellen:**
```bash
npx create-specra@latest my-awesome-docs
```

**Im aktuellen Verzeichnis erstellen:**
```bash
npx create-specra@latest .
```

**Eine bestimmte Vorlage verwenden:**
```bash
npx create-specra@latest my-docs --template minimal
npx create-specra@latest my-docs --template book-docs
npx create-specra@latest my-docs --template jbrains-docs
```

**Einen bestimmten Paketmanager verwenden:**
```bash
npx create-specra@latest my-docs --use-npm
npx create-specra@latest my-docs --use-yarn
npx create-specra@latest my-docs --use-pnpm
```

**Paketinstallation überspringen:**
```bash
npx create-specra@latest my-docs --skip-install
```

  </Step>

  <Step title="Starten Sie den Entwicklungsserver">

  </Tab>
  <Tab label="yarn">

yarn dev
```
  </Tab>

pnpm dev
```
  </Tab>

  </Step>
</Steps>

## Standardkonfiguration

Die generierte `specra.config.json` enthält sinnvolle Standardwerte:

```json
{
  "site": {
    "title": "My Documentation",
    "description": "Documentation site built with Specra",
    "url": "http://localhost:5173",
    "baseUrl": "/",
    "activeVersion": "v1.0.0"
  },
  "theme": {
    "defaultMode": "system",
    "respectPrefersColorScheme": true
  },
  "navigation": {
    "showSidebar": true,
    "collapsibleSidebar": true,
    "showBreadcrumbs": true,
    "showTableOfContents": true,
    "tocPosition": "right"
  },
  "features": {
    "showLastUpdated": true,
    "showReadingTime": true,
    "versioning": true
  }
}
```

Sie können jede dieser Einstellungen anpassen. Siehe [Konfiguration](/docs/v1.0.0/configuration/overview) für alle verfügbaren Optionen.

## Beispielinhalte

Jede Vorlage enthält Beispieldokumentation, die Ihnen den Einstieg erleichtert. Der Inhalt variiert je nach Vorlage:

**Minimal** — Über-Seite, Erste-Schritte-Anleitung und Komponentenbeispiele
**Book Docs** — Einführung mit Kartengitter, Schnellstart, Konzepte und kategorisierte Abschnitte (Inhalt, Anpassung)
**JBrains Docs** — Startseite mit Karten, Erste Schritte und Tab-Abschnitte (Grundlagen, Fortgeschritten, Tools)

Alle Vorlagen enthalten zwei Dokumentversionen (`v1.0.0` und `v2.0.0`), um das Versionierungssystem zu demonstrieren. Sie können beliebige Beispielseiten löschen oder ändern.

## Verfügbare Skripte

Die generierte `package.json` enthält diese Skripte:

| Skript | Befehl | Beschreibung |
|--------|---------|-------------|
| `dev` | `vite dev` | Startet Entwicklungsserver mit Hot Reload |
| `build` | `vite build` | Build für Produktion (verwendet standardmäßig adapter-node) |
| `preview` | `vite preview` | Vorschau des Produktions-Builds lokal |
| `check` | `svelte-kit sync && svelte-check` | Typprüfung ausführen |

## Fehlerbehebung

### Befehl nicht gefunden

Wenn Sie "command not found" Fehler erhalten:

**Node.js-Version prüfen:**
```bash
node --version
# Sollte 18.0.0 oder höher sein
```

**Mit vollem npx-Pfad versuchen:**
```bash
npx create-specra@latest my-docs
```

### Berechtigungsfehler

Unter Linux/macOS müssen Sie möglicherweise npm-Berechtigungen anpassen:

```bash
sudo chown -R $USER ~/.npm
```

Oder verwenden Sie einen Node-Versionsmanager wie [nvm](https://github.com/nvm-sh/nvm).

### Installation schlägt fehl

Wenn die Installation von Abhängigkeiten fehlschlägt:

1. Löschen Sie `node_modules` und die Lock-Datei
2. Paketmanager-Cache leeren
3. Versuchen Sie es erneut

```bash
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```
