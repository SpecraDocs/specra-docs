# Suche einrichten

Specra wird mit einer Volltextsuche ausgeliefert, die von [MeiliSearch](https://www.meilisearch.com/) angetrieben wird. Sie betreiben MeiliSearch selbst, indexieren Ihre Dokumentation darin, und Specra fragt sie für Sie ab. Diese Anleitung führt durch den gesamten Ablauf.

<Callout type="info">
  **Der Index gehört Ihnen.** Beim Indexieren werden Ihre Inhalte an *Ihren* MeiliSearch-Server gesendet — nichts wird zu Specra hochgeladen. Eine gehostete Suchoption (Indexierung über die CLI, ausgeliefert auf einer Specra-Subdomain) ist geplant; vorerst wird die Suche selbst gehostet.
</Callout>

## Suchoptionen

| Option | Einrichtung | Am besten geeignet für |
|--------|-------|----------|
| **Lokale Suche** (Standard) | Keine | Kleine Websites; sucht im Browser |
| **MeiliSearch** (empfohlen) | Server betreiben + indexieren | Mittlere/große Websites; sofortige, tippfehlertolerante, sprachbewusste Ergebnisse |

Der Rest dieser Anleitung behandelt MeiliSearch. Wenn Sie einfach nur eine konfigurationsfreie Suche möchten, springen Sie zu [Lokale Suche](#lokale-suche-alternative).

## Wie alles zusammenspielt

```txt
Browser  ──GET /api/search?q=…──▶  Ihre Specra-App (Server)  ──▶  Ihr MeiliSearch-Server
   ▲                                        │
   └──────────── Ergebnisse ◀───────────────┘
```

Der Browser kommuniziert immer nur mit der `/api/search`-Route Ihrer eigenen App. Diese Route läuft auf dem Server, liest Ihre MeiliSearch-Zugangsdaten aus `specra.config.json` und leitet die Anfrage weiter. Ihr MeiliSearch-Host und API-Schlüssel werden **niemals dem Browser offengelegt**, und es gibt keine Cross-Origin-Probleme (CORS).

## Schnellstart

**Voraussetzungen:** Ihre Specra-Dokumentationsseite (bereits eingerichtet) und ein MeiliSearch-Server (wir starten unten einen).

### 1. Einen MeiliSearch-Server betreiben

Wählen Sie, was für Sie am einfachsten ist.

**Option A — eigenständige Binärdatei (kein Docker, kein Root):**

```bash
# Die Binärdatei in den aktuellen Ordner herunterladen
curl -L https://install.meilisearch.com | sh

# Mit einem Master-Key ausführen (wählen Sie Ihren eigenen)
./meilisearch --master-key="aSampleMasterKey" --http-addr=127.0.0.1:7700
```

**Option B — Docker:**

```bash
docker run -d \
  --name meilisearch \
  -p 7700:7700 \
  -e MEILI_MASTER_KEY="aSampleMasterKey" \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest
```

In beiden Fällen lauscht MeiliSearch nun auf `http://localhost:7700`. Überprüfen Sie es:

```bash
curl http://localhost:7700/health
# {"status":"available"}
```

<Callout type="warning">
  `aSampleMasterKey` ist nur für die lokale Entwicklung. Verwenden Sie in der Produktion einen langen, zufälligen Master-Key.
</Callout>

### 2. Suche in specra.config.json aktivieren

Richten Sie Specra auf Ihren Server aus. Der `apiKey` hier wird sowohl zum Indexieren als auch zum Abfragen verwendet, setzen Sie ihn also für die lokale Entwicklung auf den **gleichen Wert** wie Ihren MeiliSearch-Master-Key.

```json
{
  "search": {
    "enabled": true,
    "provider": "meilisearch",
    "placeholder": "Search documentation...",
    "meilisearch": {
      "host": "http://localhost:7700",
      "apiKey": "aSampleMasterKey",
      "indexName": "docs"
    }
  }
}
```

### 3. Ihre Inhalte indexieren

Specra wird mit einem Indexer ausgeliefert. Aus Ihrem Projekt-Stammverzeichnis:

```bash
npm run index:search
```

Er liest `specra.config.json`, durchläuft jede Version und Sprache unter `docs/`, extrahiert den durchsuchbaren Text und überträgt die Dokumente an Ihren MeiliSearch-Server. Führen Sie ihn erneut aus, wann immer sich Ihre Dokumentation ändert.

<Callout type="info">
  Die Indexierung erfolgt auf MeiliSearch-Seite asynchron. Warten Sie ein paar Sekunden und überprüfen Sie dann mit `npm run test:search`.
</Callout>

### 4. Ausprobieren

Starten Sie Ihren Entwicklungsserver und öffnen Sie das Suchfeld mit **⌘K** (macOS) oder **Ctrl+K** (Windows/Linux):

```bash
npm run dev
```

Beginnen Sie zu tippen, um sofortige Ergebnisse zu sehen.

## Konfigurationsreferenz

Alle Einstellungen befinden sich unter `search` in `specra.config.json`:

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `enabled` | boolean | Suche ein- oder ausschalten |
| `provider` | `"meilisearch"` \| `"local"` | Such-Backend |
| `placeholder` | string | Platzhaltertext im Suchfeld |
| `meilisearch.host` | string | URL Ihres MeiliSearch-Servers |
| `meilisearch.apiKey` | string | Schlüssel zum Indexieren und Abfragen |
| `meilisearch.indexName` | string | Indexname (z. B. `docs`) |

## Sprachbewusste Suche

Wenn Ihre Website i18n verwendet, wird die Suche automatisch auf die Sprache des Lesers eingegrenzt — ohne zusätzliche Einrichtung. Der Indexer speichert ein `locale`-Feld für jedes Dokument, und `/api/search` filtert die Ergebnisse auf die Sprache, die der Leser gerade betrachtet, sodass jemand, der die französische Dokumentation liest, nur französische Treffer sieht. Der Sprachumschalter in der Kopfzeile und die Suche bleiben synchron.

## Produktion

### MeiliSearch hosten

Für die Produktion hosten Sie MeiliSearch an einem Ort, den Ihre App erreichen kann:

- **[MeiliSearch Cloud](https://www.meilisearch.com/cloud)** — verwaltet, automatische Backups und Updates.
- **Ihr eigener VPS** (DigitalOcean, AWS, Fly.io, Railway, Render…) — betreiben Sie die Binärdatei oder das Docker-Image, idealerweise hinter HTTPS.

Setzen Sie dann `meilisearch.host` auf die URL dieses Servers.

### Einen Schlüssel mit minimalen Rechten verwenden

Da Abfragen über Ihr serverseitiges `/api/search` laufen, erreicht der `apiKey` niemals den Browser. Geben Sie der App dennoch einen **nur zum Suchen** berechtigten Schlüssel und behalten Sie den Master-Key für die Indexierung.

Erstellen Sie einen nur zum Suchen berechtigten Schlüssel aus Ihrem Master-Key:

```bash
curl -X POST 'https://your-meilisearch-host/keys' \
  -H 'Authorization: Bearer YOUR_MASTER_KEY' \
  -H 'Content-Type: application/json' \
  --data-binary '{
    "description": "Search key for docs",
    "actions": ["search"],
    "indexes": ["docs"],
    "expiresAt": null
  }'
```

Verwenden Sie den zurückgegebenen Schlüssel als `meilisearch.apiKey` in Ihrer Produktions-`specra.config.json` und indexieren Sie mit dem Master-Key (siehe CI unten).

### Beim Deployment indexieren (CI/CD)

Der Indexer liest seinen Host und Schlüssel aus `specra.config.json`. Um in der CI mit Ihrem **Master-Key** zu indexieren, ohne ihn einzuchecken, generieren Sie die Konfiguration (oder überschreiben den Schlüssel) zur Build-Zeit aus einem Secret. Ein minimaler GitHub-Actions-Job:

```yaml
name: Index docs
on:
  push:
    branches: [main]
    paths: ['docs/**']

jobs:
  index:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm ci
      # Den Master-Key nur für die Indexierung in die Konfiguration einfügen
      - run: |
          node -e "const f='specra.config.json',c=require('./'+f);
            c.search.meilisearch.host=process.env.MEILI_HOST;
            c.search.meilisearch.apiKey=process.env.MEILI_MASTER_KEY;
            require('fs').writeFileSync(f, JSON.stringify(c,null,2));"
        env:
          MEILI_HOST: ${{ secrets.MEILI_HOST }}
          MEILI_MASTER_KEY: ${{ secrets.MEILI_MASTER_KEY }}
      - run: npm run index:search
```

Liefern Sie Ihre App mit dem **nur zum Suchen** berechtigten Schlüssel in `specra.config.json` aus und lassen Sie die CI den Master-Key nur für den Indexierungsschritt einsetzen.

## Den Index anpassen

Das Indexierungsverhalten befindet sich in `scripts/index-search.ts`. Es konfiguriert MeiliSearch heute so:

```ts
await index.updateSearchableAttributes(["title", "content", "tags"])
await index.updateFilterableAttributes(["version", "locale", "category", "tags"])
await index.updateSortableAttributes(["title"])
await index.updateDistinctAttribute("id")
await index.updateSettings({
  rankingRules: ["words", "typo", "proximity", "attribute", "sort", "exactness"],
})
```

Bearbeiten Sie dieses Skript, um zu ändern, was durchsuchbar ist, Synonyme oder Stoppwörter hinzuzufügen oder das Ranking anzupassen — führen Sie dann `npm run index:search` erneut aus.

## Lokale Suche (Alternative)

Sie möchten keinen Server betreiben? Verwenden Sie die integrierte lokale Suche:

```json
{
  "search": {
    "enabled": true,
    "provider": "local",
    "placeholder": "Search documentation..."
  }
}
```

- ✅ Funktioniert sofort, kein Server, kostenlos
- ❌ Keine Tippfehlertoleranz, schwächeres Ranking, langsamer bei großen Websites

## Tastenkürzel

- **⌘K** / **Ctrl+K** — Suche öffnen
- **↑ / ↓** — zwischen Ergebnissen wechseln
- **Enter** — das ausgewählte Ergebnis öffnen
- **Esc** — Suche schließen

## Fehlerbehebung

**Suchfeld erscheint nicht** — stellen Sie sicher, dass `search.enabled` in `specra.config.json` auf `true` steht.

**MeiliSearch nicht erreichbar** — überprüfen Sie den Server:

```bash
curl http://localhost:7700/health   # erwartet {"status":"available"}
```

**Keine Ergebnisse** — indexieren Sie erneut und bestätigen Sie, dass der Index existiert:

```bash
npm run index:search
curl -H "Authorization: Bearer YOUR_KEY" http://localhost:7700/indexes
```

**`/api/search` gibt "Search is not enabled" zurück** — die Route liest `specra.config.json`; stellen Sie sicher, dass `enabled` auf `true` und `provider` auf `"meilisearch"` steht, und starten Sie dann den Entwicklungsserver neu, damit die Konfiguration erneut gelesen wird.

**Ergebnisse in falscher Sprache** — führen Sie `npm run index:search` erneut aus, damit jedes Dokument sein `locale`-Feld erhält.
