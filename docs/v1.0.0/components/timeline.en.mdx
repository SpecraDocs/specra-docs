The Timeline component displays a series of events or milestones in a vertical layout, perfect for changelogs, roadmaps, and project histories.

## Usage

```mdx
<Timeline>
  <TimelineItem title="First Event">
    Description of the first event.
  </TimelineItem>

  <TimelineItem title="Second Event">
    Description of the second event.
  </TimelineItem>
</Timeline>
```

## Live Examples

### Basic Timeline

<Timeline>
  <TimelineItem title="Project Kickoff">
    The team gathered to define the project scope and initial requirements.
  </TimelineItem>

  <TimelineItem title="Design Phase">
    Created wireframes and design mockups for the application interface.
  </TimelineItem>

  <TimelineItem title="Development Sprint">
    Built the core features and integrated the backend services.
  </TimelineItem>

  <TimelineItem title="Launch">
    Deployed the application to production and announced the public release.
  </TimelineItem>
</Timeline>

### Timeline with Rich Content

Each `TimelineItem` accepts full MDX — bold text, links, inline code, and other components like `Badge`.

<Timeline>
  <TimelineItem title="Stable Release" date="April 2026">
    **v2.0.0** shipped. Adds the API playground and plugin system. <Badge>stable</Badge>
  </TimelineItem>

  <TimelineItem title="Search & Timeline" date="March 2026">
    Added the `Timeline` component and language-aware search. Re-run `npm run index:search` to pick up new content.
  </TimelineItem>

  <TimelineItem title="First Release" date="January 2026">
    First stable release with versioning, i18n, and MeiliSearch integration. See the [changelog](/docs/v1.0.0/changelog).
  </TimelineItem>
</Timeline>

## Props

### Timeline

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `Snippet` | required | TimelineItem components |

### TimelineItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | required | Event title/heading |
| `date` | `string` | — | Optional date or time label |
| `children` | `Snippet` | required | Event content |

## Features

- **Automatic Numbering** — Events are numbered automatically using CSS counters
- **Visual Connector** — A vertical line connects all events in sequence
- **Date Labels** — Optionally display dates or time periods for each event
- **Rich Content** — Each event supports full MDX content including code blocks and components

<Callout type="tip">
Use Timeline for changelogs, release histories, and project roadmaps. For step-by-step instructions, use the Steps component instead.
</Callout>
