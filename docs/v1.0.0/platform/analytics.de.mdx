# Analysen

Spectra Platform enthält integrierte, datenschutzfreundliche Analysen für Ihre Dokumentationsseiten. Keine Drittanbieter-Skripte, keine Cookie-Banner — nur die Daten, die Sie brauchen, um zu verstehen, wie Ihre Docs genutzt werden.

<Callout type="info">
  Analysen erfordern einen **Starter**-Tarif oder höher. Free-Tarif-Projekte haben keinen Zugang zu Analysen.
</Callout>

## Was wir erfassen

### Seitenaufrufe und Besucher

- **Gesamte Seitenaufrufe** — wie oft Ihre Seiten geladen wurden
- **Einzigartige Besucher** — unterschiedliche Sitzungen, die Ihre Seite besuchen
- **Absprungrate** — Prozentsatz der Besucher, die nur eine Seite angesehen haben
- **Durchschnittliche Sitzungsdauer** — wie lange Besucher auf Ihren Docs verbringen
- **Scroll-Tiefe** — wie weit Besucher auf der Seite nach unten scrollen
- **Top-Seiten** — Ihre meistbesuchten Dokumentationsseiten

### Geografie

- **Land** — aus welchen Ländern Ihre Besucher kommen
- **Region** — Daten auf Bundesland-/Provinzebene
- **Stadt** — Standortdaten auf Stadtebene

### Geräte

- **Browser** — Chrome, Firefox, Safari, Edge usw.
- **Betriebssystem** — Windows, macOS, Linux, iOS, Android
- **Gerätetyp** — Desktop, Mobil oder Tablet

### Referrer

Sehen Sie, woher Ihr Traffic kommt — Suchmaschinen, soziale Medien, direkte Links oder andere Websites.

### Sitzungen

Jede Besuchersitzung wird mit einer eindeutigen Sitzungs-ID verfolgt. Sitzungen werden verwendet, um Absprungrate, Sitzungsdauer und einzigartige Besucherzahlen zu berechnen.

## Zeiträume

Sie können Analysen für vier Zeitfenster anzeigen:

| Zeitraum | Beschreibung |
|----------|-------------|
| **24 Stunden** | Letzter Tag der Aktivität |
| **7 Tage** | Letzte Woche |
| **30 Tage** | Letzter Monat |
| **90 Tage** | Letztes Quartal |

## Echtzeit-Besucher

Das Dashboard zeigt die Anzahl der derzeit aktiven Besucher auf Ihrer Seite (aktiv innerhalb der letzten 5 Minuten).

## Auf Analysen zugreifen

Navigieren Sie zu Ihrem Projekt im Dashboard und klicken Sie auf **Analysen** in der Seitenleiste. Sie sehen eine Übersicht mit:

- Gesamtaufrufe und einzigartige Besucher
- Absprungrate und durchschnittliche Dauer
- Top-Seiten-Diagramm
- Geografische Aufschlüsselungskarte
- Geräte- und Browser-Diagramme
- Referrer-Liste

## Datenschutz

Spectra Analytics wurde mit Datenschutz im Sinn entwickelt:

- Keine Cookies werden für das Tracking verwendet
- Keine personenbezogenen Daten (PII) werden erfasst
- Daten werden sicher gespeichert und nie an Dritte weitergegeben
- Konform mit DSGVO und CCPA
- Kein Cookie-Zustimmungsbanner erforderlich

<Callout type="tip">
  Da Spectra Analytics keine Cookies verwendet, müssen Sie kein Cookie-Zustimmungsbanner auf Ihrer Dokumentationsseite anzeigen.
</Callout>
