# Organisations

Les organisations permettent aux équipes de collaborer sur des projets de documentation avec un contrôle d'accès basé sur les rôles. Les organisations sont disponibles sur les forfaits **Pro** et **Enterprise**.

## Créer une Organisation

1. Allez sur votre [tableau de bord](https://specra-docs.com/dashboard)
2. Cliquez sur **Organisations** dans la barre latérale
3. Cliquez sur **Créer une Organisation**
4. Entrez un nom et une description optionnelle

La personne qui crée l'organisation devient automatiquement le **Propriétaire**.

## Rôles

Chaque membre de l'organisation a l'un des trois rôles :

| Rôle | Permissions |
|------|------------|
| **Propriétaire** | Accès complet. Gère la facturation, les membres, les rôles et tous les projets. Peut supprimer l'organisation. Un propriétaire par org. |
| **Administrateur** | Gère les membres et les projets. Ne peut pas modifier la facturation ni supprimer l'organisation. |
| **Membre** | Consulte et déploie sur les projets assignés. Ne peut pas gérer les membres ni la facturation. |

<Callout type="info">
  La propriété peut être transférée à un autre membre depuis **Paramètres de l'Organisation > Général**.
</Callout>

## Inviter des Membres

<Steps>
  <Step title="Ouvrez l'Organisation">
    Allez dans **Organisations > Votre Org > Membres**.
  </Step>
  <Step title="Envoyez une Invitation">
    Cliquez sur **Inviter un Membre**, entrez son adresse e-mail et choisissez un rôle (Administrateur ou Membre).
  </Step>
  <Step title="Acceptation">
    L'invité reçoit un e-mail avec un lien pour accepter l'invitation. Il doit avoir un compte Specra (ou en créer un) pour rejoindre.
  </Step>
</Steps>

Les invitations en attente comptent dans votre utilisation de places. Vous pouvez annuler les invitations en attente depuis la page Membres.

## Gestion des Places

Votre forfait détermine combien de places sont incluses et combien coûtent les places supplémentaires :

| Forfait | Places de Base | Coût des Places Supplémentaires |
|---------|---------------|-------------------------------|
| Pro | 10 | 8 $/place/mois |
| Enterprise | Illimitées | Incluses |

### Acheter des Places Supplémentaires

Si vous avez besoin de plus de places que votre forfait n'en inclut :

1. Allez dans **Paramètres de l'Organisation > Facturation**
2. Cliquez sur **Ajouter des Places**
3. Choisissez combien de places supplémentaires vous avez besoin
4. Les places supplémentaires sont facturées mensuellement en plus du prix de votre forfait

<Callout type="tip">
  Les frais pour les places supplémentaires sont au prorata. Si vous ajoutez une place en milieu de cycle, vous ne payez que pour les jours restants de cette période de facturation.
</Callout>

### Retirer des Membres

Les Administrateurs et Propriétaires peuvent retirer des membres depuis **Organisation > Membres**. Le retrait d'un membre libère une place immédiatement.

## Projets d'Organisation

Les projets peuvent appartenir à une organisation plutôt qu'à un utilisateur individuel. Tous les membres de l'organisation avec les permissions appropriées peuvent accéder aux projets de l'organisation.

Pour déplacer un projet personnel dans une organisation :

1. Allez dans **Paramètres du Projet > Général**
2. Sous **Transférer le Projet**, sélectionnez l'organisation cible
3. Confirmez le transfert

<Callout type="warning">
  Le transfert d'un projet vers une organisation est irréversible depuis le tableau de bord. Contactez le support si vous devez l'annuler.
</Callout>
