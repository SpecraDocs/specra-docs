# Aperçu de la Plateforme

Specra Platform est le service hébergé qui fait fonctionner vos sites de documentation. Il gère le déploiement, l'hébergement, les analyses et la collaboration en équipe pour que vous puissiez vous concentrer sur la rédaction d'une documentation de qualité.

## Comment ça Fonctionne

Mettre votre documentation en ligne ne nécessite que quatre étapes :

<Steps>
  <Step title="Inscrivez-vous">
    Créez un compte sur [specra-docs.com](https://specra-docs.com). Vous pouvez vous inscrire avec GitHub, Google ou par e-mail.
  </Step>
  <Step title="Créez un Projet">
    Chaque projet représente un site de documentation. Donnez-lui un nom et vous obtiendrez un sous-domaine comme `votre-projet.specra-docs.com`, ou connectez votre propre domaine personnalisé.
  </Step>
  <Step title="Déployez">
    Publiez vos docs avec la CLI Specra, connectez un dépôt GitHub pour des déploiements automatiques, ou téléchargez un build manuellement via le tableau de bord.
  </Step>
  <Step title="Surveillez">
    Suivez les vues de pages, les analyses de visiteurs et l'état des déploiements depuis le tableau de bord de votre projet. Gérez votre équipe, la facturation et les paramètres en un seul endroit.
  </Step>
</Steps>
