# Platform Overview

Specra Platform is the hosted service that powers your documentation sites. It handles deployment, hosting, analytics, and team collaboration so you can focus on writing great docs.

## How It Works

Getting your documentation live takes just four steps:

<Steps>
  <Step title="Sign Up">
    Create an account at [specra-docs.com](https://specra-docs.com). You can sign up with GitHub, Google, or email.
  </Step>
  <Step title="Create a Project">
    Each project represents one documentation site. Give it a name and you'll get a subdomain like `your-project.specra-docs.com`, or connect your own custom domain.
  </Step>
  <Step title="Deploy">
    Push your docs using the Specra CLI, connect a GitHub repository for automatic deployments, or upload a build manually through the dashboard.
  </Step>
  <Step title="Monitor">
    Track page views, visitor analytics, and deployment status from your project dashboard. Manage your team, billing, and settings all in one place.
  </Step>
</Steps>
