# Plattform-Übersicht

Specra Platform ist der gehostete Dienst, der Ihre Dokumentationsseiten betreibt. Er kümmert sich um Bereitstellung, Hosting, Analysen und Team-Zusammenarbeit, damit Sie sich auf das Schreiben großartiger Dokumentation konzentrieren können.

## So funktioniert es

Ihre Dokumentation live zu bringen, erfordert nur vier Schritte:

<Steps>
  <Step title="Registrieren">
    Erstellen Sie ein Konto auf [specra-docs.com](https://specra-docs.com). Sie können sich mit GitHub, Google oder E-Mail registrieren.
  </Step>
  <Step title="Projekt erstellen">
    Jedes Projekt repräsentiert eine Dokumentationsseite. Geben Sie ihm einen Namen und Sie erhalten eine Subdomain wie `ihr-projekt.specra-docs.com`, oder verbinden Sie Ihre eigene Domain.
  </Step>
  <Step title="Bereitstellen">
    Laden Sie Ihre Docs mit der Specra CLI hoch, verbinden Sie ein GitHub-Repository für automatische Bereitstellungen oder laden Sie einen Build manuell über das Dashboard hoch.
  </Step>
  <Step title="Überwachen">
    Verfolgen Sie Seitenaufrufe, Besucheranalysen und den Bereitstellungsstatus von Ihrem Projekt-Dashboard aus. Verwalten Sie Ihr Team, die Abrechnung und Einstellungen an einem Ort.
  </Step>
</Steps>
