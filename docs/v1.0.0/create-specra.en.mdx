# create-specra

`create-specra` is the official CLI tool for scaffolding new Specra documentation sites. It sets up everything you need in seconds: project structure, dependencies, configuration, and sample content.

<Callout type="info">
`create-specra` also includes commands for deploying, authentication, and diagnostics. See the full [CLI Reference](/docs/v1.0.0/cli/overview) for all available commands.
</Callout>

## Quick Start

The fastest way to create a new documentation site:

<Tabs defaultValue="npm">
  <Tab label="npm">
```bash
npx create-specra@latest my-docs
```
  </Tab>
  <Tab label="yarn">
```bash
yarn create specra my-docs
```
  </Tab>
  <Tab label="pnpm">
```bash
pnpm create specra my-docs
```
  </Tab>
</Tabs>

This creates a new directory called `my-docs` with everything configured and ready to go.

## What Gets Created

When you run `create-specra`, here's what you get:

```txt
my-docs/
├── src/
│   ├── app.css                    # Global styles (imports specra/styles)
│   ├── app.html                   # HTML template
│   └── routes/
│       ├── +layout.server.ts      # Load Specra config
│       ├── +layout.svelte         # Root layout with Specra components
│       ├── +page.server.ts        # Landing page redirect
│       └── docs/
│           └── [version]/
│               └── [...slug]/
│                   ├── +page.server.ts   # Load doc data
│                   └── +page.svelte      # Doc page renderer
├── docs/
│   ├── v1.0.0/                    # Version 1 docs (MDX files)
│   └── v2.0.0/                    # Version 2 docs (MDX files)
├── public/
│   └── api-specs/                 # API spec files (OpenAPI, Postman)
├── specra.config.json             # Specra configuration
├── package.json                   # Dependencies and scripts
├── svelte.config.js               # SvelteKit configuration
├── vite.config.ts                 # Vite configuration
├── postcss.config.mjs             # PostCSS (for Tailwind)
├── tsconfig.json                  # TypeScript config
└── .gitignore
```

## Templates

`create-specra` offers three templates to choose from:

### Minimal (Default)

Clean starting point with basic structure:
- System theme (follows OS preference)
- Card-style sidebar with rounded container
- Table of contents enabled
- Simple docs: about page, getting started guide, component examples

```bash
npx create-specra my-docs --template minimal
```

### Book Docs

Knowledge base style inspired by platforms like GitBook:
- Dark theme by default
- Flush sidebar (attached to screen edge)
- Categorized sidebar with section headers (Content, Customization)
- Site-wide banner
- Version badge in sidebar
- Rich sample content with cards on landing page

```bash
npx create-specra my-docs --template book-docs
```

### JBrains Docs

Reference documentation style with tabbed navigation:
- Light theme by default
- Flush sidebar (attached to screen edge)
- Tab groups for organizing content (Language, Multiplatform)
- Collapsible tree-style sidebar
- No table of contents (right panel)
- Version badge in sidebar

```bash
npx create-specra my-docs --template jbrains-docs
```

## Interactive Setup

When you run `create-specra` without options, it will prompt you for:

**Project name** (if not provided as argument)
```bash
npx create-specra@latest
# Prompts: What is your project named?
```

**Template** (if not provided via `--template`)
```bash
# Will ask: Which template do you want to use?
# Options: Minimal, Book Docs, JBrains Docs
```

**Package manager preference** (if multiple are detected)
```bash
# Will ask: Which package manager do you want to use?
# Options: npm, yarn, pnpm
```

The CLI detects what's available on your system and suggests the best option.

## Command Options

### Basic Usage

```bash
npx create-specra@latest [project-name] [options]
```

### Examples

**Create with a specific name:**
```bash
npx create-specra@latest my-awesome-docs
```

**Create in current directory:**
```bash
npx create-specra@latest .
```

**Use a specific template:**
```bash
npx create-specra@latest my-docs --template minimal
npx create-specra@latest my-docs --template book-docs
npx create-specra@latest my-docs --template jbrains-docs
```

**Use a specific package manager:**
```bash
npx create-specra@latest my-docs --use-npm
npx create-specra@latest my-docs --use-yarn
npx create-specra@latest my-docs --use-pnpm
```

**Skip package installation:**
```bash
npx create-specra@latest my-docs --skip-install
```

## Default Configuration

The generated `specra.config.json` includes sensible defaults:

```json
{
  "site": {
    "title": "My Documentation",
    "description": "Documentation site built with Specra",
    "url": "http://localhost:5173",
    "baseUrl": "/",
    "activeVersion": "v1.0.0"
  },
  "theme": {
    "defaultMode": "system",
    "respectPrefersColorScheme": true
  },
  "navigation": {
    "showSidebar": true,
    "collapsibleSidebar": true,
    "showBreadcrumbs": true,
    "showTableOfContents": true,
    "tocPosition": "right"
  },
  "features": {
    "showLastUpdated": true,
    "showReadingTime": true,
    "versioning": true
  }
}
```

You can customize any of these settings. See [Configuration](/docs/v1.0.0/configuration/overview) for all available options.

## Sample Content

Each template includes sample documentation to help you get started. The content varies by template:

**Minimal** — About page, getting started guide, and component examples
**Book Docs** — Introduction with card grid, quickstart, concepts, and categorized sections (Content, Customization)
**JBrains Docs** — Home page with cards, getting started, and tabbed sections (Basics, Advanced, Tools)

All templates include two doc versions (`v1.0.0` and `v2.0.0`) to demonstrate the versioning system. Feel free to delete or modify any sample pages.

## Available Scripts

The generated `package.json` includes these scripts:

| Script | Command | Description |
|--------|---------|-------------|
| `dev` | `vite dev` | Start development server with hot reload |
| `build` | `vite build` | Build for production (uses adapter-node by default) |
| `preview` | `vite preview` | Preview the production build locally |
| `check` | `svelte-kit sync && svelte-check` | Run type checking |

## Troubleshooting

### Command not found

If you get "command not found" errors:

**Check Node.js version:**
```bash
node --version
# Should be 18.0.0 or higher
```

**Try with full npx path:**
```bash
npx create-specra@latest my-docs
```

### Permission errors

On Linux/macOS, you might need to adjust npm permissions:

```bash
sudo chown -R $USER ~/.npm
```

Or use a node version manager like [nvm](https://github.com/nvm-sh/nvm).

### Installation fails

If dependency installation fails:

1. Delete `node_modules` and lock file
2. Clear package manager cache
3. Try again

```bash
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```
