# create-specra

`create-specra` es la herramienta CLI oficial para crear nuevos sitios de documentación Specra. Configura todo lo que necesita en segundos: estructura del proyecto, dependencias, configuración y contenido de muestra.

<Callout type="info">
`create-specra` también incluye comandos para despliegue, autenticación y diagnósticos. Vea la [Referencia CLI](/docs/v1.0.0/cli/overview) completa para todos los comandos disponibles.
</Callout>

## Inicio rápido

La forma más rápida de crear un nuevo sitio de documentación:

<Tabs defaultValue="npm">
  <Tab label="npm">
```bash
npx create-specra@latest my-docs
```
  </Tab>
  <Tab label="yarn">
```bash
yarn create specra my-docs
```
  </Tab>
  <Tab label="pnpm">
```bash
pnpm create specra my-docs
```
  </Tab>
</Tabs>

Esto crea un nuevo directorio llamado `my-docs` con todo configurado y listo para usar.

## Qué se crea

Cuando ejecuta `create-specra`, esto es lo que obtiene:

```txt
my-docs/
├── src/
│   ├── app.css                    # Estilos globales (importa specra/styles)
│   ├── app.html                   # Plantilla HTML
│   └── routes/
│       ├── +layout.server.ts      # Cargar configuración de Specra
│       ├── +layout.svelte         # Layout raíz con componentes Specra
│       ├── +page.server.ts        # Redirección de página principal
│       └── docs/
│           └── [version]/
│               └── [...slug]/
│                   ├── +page.server.ts   # Cargar datos del documento
│                   └── +page.svelte      # Renderizador de páginas de documentación
├── docs/
│   ├── v1.0.0/                    # Docs versión 1 (archivos MDX)
│   └── v2.0.0/                    # Docs versión 2 (archivos MDX)
├── public/
│   └── api-specs/                 # Archivos de especificación API (OpenAPI, Postman)
├── specra.config.json             # Configuración de Specra
├── package.json                   # Dependencias y scripts
├── svelte.config.js               # Configuración de SvelteKit
├── vite.config.ts                 # Configuración de Vite
├── postcss.config.mjs             # PostCSS (para Tailwind)
├── tsconfig.json                  # Config de TypeScript
└── .gitignore
```

## Plantillas

`create-specra` ofrece tres plantillas para elegir:

### Minimal (Predeterminada)

Punto de partida limpio con estructura básica:
- Tema del sistema (sigue la preferencia del SO)
- Barra lateral estilo tarjeta con contenedor redondeado
- Tabla de contenidos habilitada
- Docs simples: página acerca de, guía de inicio, ejemplos de componentes

```bash
npx create-specra my-docs --template minimal
```

### Book Docs

Estilo de base de conocimiento inspirado en plataformas como GitBook:
- Tema oscuro por defecto
- Barra lateral al ras (pegada al borde de la pantalla)
- Barra lateral categorizada con encabezados de sección (Contenido, Personalización)
- Banner en todo el sitio
- Insignia de versión en la barra lateral
- Contenido de muestra enriquecido con tarjetas en la página principal

```bash
npx create-specra my-docs --template book-docs
```

### JBrains Docs

Estilo de documentación de referencia con navegación por pestañas:
- Tema claro por defecto
- Barra lateral al ras (pegada al borde de la pantalla)
- Grupos de pestañas para organizar contenido (Lenguaje, Multiplataforma)
- Barra lateral colapsable estilo árbol
- Sin tabla de contenidos (panel derecho)
- Insignia de versión en la barra lateral

```bash
npx create-specra my-docs --template jbrains-docs
```

## Configuración interactiva

Cuando ejecuta `create-specra` sin opciones, le solicitará:

**Nombre del proyecto** (si no se proporciona como argumento)
```bash
npx create-specra@latest
# Pregunta: What is your project named?
```

**Plantilla** (si no se proporciona vía `--template`)
```bash
# Preguntará: Which template do you want to use?
# Opciones: Minimal, Book Docs, JBrains Docs
```

**Preferencia de gestor de paquetes** (si se detectan múltiples)
```bash
# Preguntará: Which package manager do you want to use?
# Opciones: npm, yarn, pnpm
```

La CLI detecta lo que está disponible en su sistema y sugiere la mejor opción.

## Opciones de comando

### Uso básico

```bash
npx create-specra@latest [project-name] [options]
```

### Ejemplos

**Crear con un nombre específico:**
```bash
npx create-specra@latest my-awesome-docs
```

**Crear en el directorio actual:**
```bash
npx create-specra@latest .
```

**Usar una plantilla específica:**
```bash
npx create-specra@latest my-docs --template minimal
npx create-specra@latest my-docs --template book-docs
npx create-specra@latest my-docs --template jbrains-docs
```

**Usar un gestor de paquetes específico:**
```bash
npx create-specra@latest my-docs --use-npm
npx create-specra@latest my-docs --use-yarn
npx create-specra@latest my-docs --use-pnpm
```

**Omitir instalación de paquetes:**
```bash
npx create-specra@latest my-docs --skip-install
```

## Contenido de muestra

Cada plantilla incluye documentación de muestra para ayudarle a comenzar. El contenido varía según la plantilla:

**Minimal** — Página acerca de, guía de inicio y ejemplos de componentes
**Book Docs** — Introducción con cuadrícula de tarjetas, inicio rápido, conceptos y secciones categorizadas (Contenido, Personalización)
**JBrains Docs** — Página principal con tarjetas, primeros pasos y secciones con pestañas (Básicos, Avanzado, Herramientas)

Todas las plantillas incluyen dos versiones de documentación (`v1.0.0` y `v2.0.0`) para demostrar el sistema de versionado. Siéntase libre de eliminar o modificar cualquier página de muestra.

## Scripts disponibles

El `package.json` generado incluye estos scripts:

| Script | Comando | Descripción |
|--------|---------|-------------|
| `dev` | `vite dev` | Inicia servidor de desarrollo con recarga en caliente |
| `build` | `vite build` | Compila para producción (usa adapter-node por defecto) |
| `preview` | `vite preview` | Vista previa del build de producción localmente |
| `check` | `svelte-kit sync && svelte-check` | Ejecuta verificación de tipos |

## Solución de problemas

### Comando no encontrado

Si obtiene errores de "command not found":

**Verifique la versión de Node.js:**
```bash
node --version
# Debería ser 18.0.0 o superior
```

**Intente con la ruta completa de npx:**
```bash
npx create-specra@latest my-docs
```

### Errores de permiso

En Linux/macOS, es posible que necesite ajustar los permisos de npm:

```bash
sudo chown -R $USER ~/.npm
```

O use un administrador de versiones de nodo como [nvm](https://github.com/nvm-sh/nvm).

### La instalación falla

Si la instalación de dependencias falla:

1. Elimine `node_modules` y el archivo de bloqueo
2. Limpie la caché del gestor de paquetes
3. Intente de nuevo

```bash
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```
