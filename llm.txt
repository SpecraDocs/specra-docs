# Specra Docs - AI-Friendly Documentation

## Project Overview
specra-docs is the official documentation website for Specra. It serves as both comprehensive documentation for users and a reference implementation demonstrating Specra's capabilities.

## Key Information
- Project Name: specra-docs
- Type: Documentation Website + SaaS Platform / SvelteKit Application
- Purpose: Document Specra framework, demonstrate its features, and offer paid SaaS tiers
- URL: https://specra-docs.com (self-hosted with Caddy)
- Repository: https://github.com/dalmasonto/specra-docs
- Built With: Specra (dogfooding)

## Core Purpose
1. **Documentation**: Comprehensive guides, API references, and tutorials for Specra
2. **Reference Implementation**: Real-world example of Specra in production
3. **Showcase**: Demonstrates all Specra features and capabilities
4. **Onboarding**: Helps new users learn and adopt Specra

## Technology Stack
- SvelteKit 2 (with adapter-node for production)
- Svelte 5
- Specra 0.2.0 (the SDK this project documents)
- Tailwind CSS 4
- TypeScript 5
- Auth.js (@auth/sveltekit) - Authentication (GitHub OAuth + credentials)
- Prisma v7 + PostgreSQL - Database ORM
- Stripe (Checkout + Webhooks + Customer Portal) - International payments (USD)
- M-Pesa Daraja API (STK Push) - Kenya payments (KES)
- bcryptjs - Password hashing
- Deployed self-hosted with Caddy reverse proxy

## Key Features
- Comprehensive Specra documentation
- Multi-version documentation support (v1.0.0)
- Tab groups for organized navigation (Guides, API Reference, Components)
- Dark mode support
- Responsive design
- Custom landing page
- Search functionality (MeiliSearch, currently disabled)
- Social links (GitHub, Twitter, Discord)
- Custom footer with links

### SaaS / Payment Features
- 4 pricing tiers: Free, Starter ($19/mo), Pro ($49/mo), Enterprise ($149/mo)
- Dual payment providers: Stripe (international, USD) + M-Pesa (Kenya, KES)
- Annual billing discounts (save ~20%)
- Auth: GitHub OAuth + email/password via Auth.js
- User dashboard: plan overview, billing management, payment history
- Stripe Customer Portal: manage subscription, update payment method
- M-Pesa STK Push: phone-prompted payments for Kenyan users
- Webhook-driven subscription lifecycle (auto-activate, cancel, handle failures)
- Route protection via hooks.server.ts (dashboard requires authentication)

## Build Scripts
- `dev`: Development server (vite dev)
- `build`: Production build (vite build, outputs to build/)
- `preview`: Preview production build (vite preview)
- `start`: Production server (node build)
- `check`: Type checking (svelte-check)
- `index:search`: Index content in MeiliSearch
- `test:search`: Test search functionality
- `seed-admin`: Seed admin user

## Deployment Options
1. **Self-hosted with Docker + Caddy (Production)**: `npm run build && node build`
   - Caddy reverse proxies to localhost:3000
   - Docker containerization with multi-stage build
   - Supports API routes, Auth.js, webhooks
2. **Vercel**: `npm run build` with adapter-vercel
3. **Netlify**: `npm run build` with adapter-netlify

## Payment System Architecture

### Database (Prisma v7 + PostgreSQL)
- Schema: prisma/schema.prisma
- Config: prisma/prisma.config.ts (Prisma v7 requires this for datasource URL)
- Models: User, Account, Session, VerificationToken, Plan, Subscription, Payment, Invoice, Coupon, TaxConfig, Organization, Project, Deployment, ApiToken, AuditLog
- Client singleton: src/lib/server/db.ts

### Authentication (Auth.js)
- Config: src/lib/server/auth.ts (GitHub OAuth + credentials providers, JWT sessions, Prisma adapter)
- Middleware: src/hooks.server.ts (protects /dashboard/*, /admin/*, redirects auth pages if logged in)
- Registration: src/routes/api/auth/register/+server.ts (bcrypt hashing)

### Stripe (International, USD)
- Client: src/lib/server/stripe.ts
- Checkout: src/routes/api/stripe/checkout/+server.ts
- Portal: src/routes/api/stripe/portal/+server.ts
- Webhooks: src/routes/api/webhooks/stripe/+server.ts

### M-Pesa Daraja (Kenya, KES)
- Client: src/lib/server/mpesa.ts (OAuth, STK Push, status query, phone normalization)
- STK Push: src/routes/api/mpesa/stkpush/+server.ts
- Callback: src/routes/api/mpesa/callback/+server.ts
- Status: src/routes/api/mpesa/status/+server.ts

### Environment Variables (.env.local)
DATABASE_URL, AUTH_SECRET, AUTH_GITHUB_ID, AUTH_GITHUB_SECRET,
STRIPE_SECRET_KEY, PUBLIC_STRIPE_PUBLISHABLE_KEY, STRIPE_WEBHOOK_SECRET,
MPESA_CONSUMER_KEY, MPESA_CONSUMER_SECRET, MPESA_SHORTCODE, MPESA_PASSKEY,
MPESA_CALLBACK_URL, MPESA_ENV, PUBLIC_APP_URL

## Search Integration
MeiliSearch configuration (currently disabled):
- Host: http://localhost:7700
- API Key: aSampleMasterKey
- Index Name: docs

To enable:
1. Set `search.enabled: true` in specra.config.json
2. Run MeiliSearch instance
3. Run `npm run index:search` to index content
4. Search UI automatically appears
